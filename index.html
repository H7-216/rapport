Comment fonctionne l'IA ici ?

    

    Dans le navigateur
    Un vrai modèle de langage (Qwen 2.5 ou Llama 3.2) tourne sur votre carte graphique grâce à WebGPU. Le premier chargement télécharge le modèle, ensuite il démarre en quelques secondes, même hors ligne.
    Si le chargement échoue en ouvrant le fichier en double-clic, lancez python -m http.server dans le dossier puis ouvrez http://localhost:8000.
    

    Serveur local
    Si vous avez déjà Ollama ou LM Studio, la page s'y connecte directement : modèles plus gros, meilleure qualité, toujours en local.
    Bouton « Tester la connexion » pour récupérer la liste des modèles installés.
    

    Dans l'éditeur
    Le bouton ✦ de chaque bloc permet de rédiger une partie, développer, reformuler, corriger ou résumer un paragraphe. Une action peut toujours être annulée depuis la notification.
